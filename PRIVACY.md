# TaskTape privacy policy

_Last updated: November 2026_

TaskTape is a browser extension that records and replays actions you choose to record.

**What is stored.** The steps of your automations (pages visited, the elements you clicked, the text you typed), their settings, the last 20 run results, and the last values you entered for run-time variables. Passwords typed while recording are replaced by a placeholder and are never stored. For file uploads, only the file name is kept; the file's content is never read into storage. You choose the file again at each run, and it goes straight from your computer into the page. Variable values whose name looks secret (password, PIN, token) are never stored.

**Where it is stored.** Only in your browser, using the extension storage of your browser profile. Nothing is sent to the developer or to any third party. TaskTape has no server, no account and no analytics.

**What is shared.** Nothing, unless you export an automation to a file yourself and send it to someone. Check exported files before sharing them: they contain the text you typed while recording.

**Permissions.** Access to websites is used only to record and replay actions on the pages where you start a recording or a run. TaskTape does not read pages otherwise.

**Deleting your data.** Delete automations in the manager, or remove the extension: Chrome then deletes all its data.

**Contact.** Open an issue on the project's repository.
