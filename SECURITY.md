# Security policy

TaskTape runs in your browser and can act on any page where you start a recording or a run, so security problems are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately instead:

👉 [Report a vulnerability](https://github.com/uuduru/TaskTape/security/advisories/new)

Include what an attacker could do, the steps to reproduce it, and your browser version. You will get an answer as soon as possible. Once a fix is published, you will be credited, unless you prefer to stay anonymous.

## Supported versions

Only the latest version of TaskTape receives fixes.
